# Build brief

Deadline: September 12, 2026, 4:30 PM EDT (Columbus portal). Submit by 4:00 PM.

Submission needs: title, written description, this public repo, a two-minute video, a public social post tagging the event partners.

Judging: four criteria, each scored 1 to 5. Functionality, Innovation and theme, Technical execution, Usefulness. Sponsor SDK count is not a criterion.

Core interaction to demo end to end:
1. Hotkey on any page. Page title, URL, selection, and visible text are captured locally.
2. Voice note transcribed. Transcript plus page context go to the agent.
3. Agent proposes one action (task, doc, calendar item). Card shows exactly what will be written.
4. Approve. Record is created in Ambiguous with a link back to the page and a prefilled session link.
5. Read back after refresh. Show the real record.
6. Show one failure path: transcription uncertain, or write rejected, and how the user recovers.
