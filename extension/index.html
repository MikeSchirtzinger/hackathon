What’s running?

Nemotron Speech Streaming English 0.6B (560 ms configuration) and Kokoro English v0.19, both quantized to INT8. Each runs in its own Web Worker using sherpa-onnx 1.13.8 and ONNX Runtime WASM. All runtime and model files are bundled with this extension. Model loading can take a while and uses substantial RAM. This is a speech demo; it does not include a chatbot.
